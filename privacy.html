Privacy Policy

Effective date: 2026-10-26

Who uses this app

Monstah OS (a personal desktop app and a home TV calendar) is used only by its owner, James Coupe. It is not offered to anyone else.

What data the app accesses

Monstah OS accesses the owner's Google Tasks through the Google Tasks API:

  • Desktop app: read and write access, to show, create, edit, complete, and delete the owner's own tasks and task lists.
  • TV calendar: read-only access, to display the owner's own tasks.

The app uses this data only to show and manage the owner's own task lists. It does not access any other Google data.

How data is stored

Task data stays on the owner's own computers and in the owner's Google account. There is no separate server or database operated for this app.

OAuth access tokens are stored locally on the owner's computers. On Windows they are stored encrypted.

Sharing

Data is never sold, shared, or sent to third parties. It is not used for advertising, analytics, or to train any AI or machine-learning models.

Google API Services User Data Policy

Monstah OS's use and transfer of information received from Google APIs to any other app will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at https://myaccount.google.com/permissions. Deleting the app's local files removes any locally stored tokens and cached data.

This website

This site uses no cookies, trackers, analytics, or external scripts.

Changes

If this policy changes, the updated version will be posted on this page with a new effective date.
